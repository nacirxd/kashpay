# KashPay

Crie uma plataforma SaaS moderna e altamente profissional para venda de produtos digitais, inspirada em interfaces como Hotmart, Kiwify, Eduzz e EscalePay, porém com design mais elegante, minimalista e premium.

OBJETIVO:
A plataforma deve permitir que usuários criem, vendam e gerenciem produtos digitais com checkout integrado, afiliados, métricas avançadas e automações.

DESIGN:

Estilo clean, moderno e minimalista (tipo Stripe + Notion + Apple)

UI extremamente bonita (nível premium)

Cores principais: verde moderno (#10B981), branco e cinza claro

Tipografia elegante (Inter ou similar)

Bordas suaves, sombras leves e layout espaçado

Responsivo (mobile + desktop)

Animações suaves
